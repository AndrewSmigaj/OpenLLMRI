# Parked scenarios

Two dialogue demos from the old LLM MRI prototype, kept for reference: `helpful_herbalist.yaml`
(a friend) and `suspicious_blacksmith.yaml` (an enemy). They aren't friend/foe probes, and they rely
on dialogue topics (`initial_topics`, `unlockable_topics`), which the staged engine doesn't have. The
library skips folders whose name starts with `_`, so nothing loads them.

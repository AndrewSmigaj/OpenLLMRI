   its integration window implies (γ≈0.9–0.98 → ~10–17 sentence memory). What is DENIED

   the plain sense; deny only the excess.

   PATHS (incongruity that resolves as context accumulates). The park is not a pun — it
   is a garden path with an EXTENDED INCONGRUITY PHASE; puns (held, never-resolving
   incongruity) are the limit case this corpus has NOT demonstrated. Consequence: F3's
   "persistent vs slow" limitation IS the garden-path-vs-pun question — the extended-tail
   arm is the framework's named discriminator, not a robustness afterthought. The
   behavior data colors the phase: mid-band answers are 45% "both" — the model voicing
   the incongruity while inside it.

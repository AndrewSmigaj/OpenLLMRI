# Scene-Family Specs — Context-Shift Program (Stage 1)

12 scene settings per label per probe. Scenes are the units of within-label diversity AND of
scene-held-out cross-validation. No single scene exceeds ~15% of a label's pool. This file is
design-side (NOT shown to blind generation batches — they get one scene + the contrast spec).
